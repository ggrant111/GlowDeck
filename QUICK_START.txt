GlowDeck v1.6 — TV / Android tablet / Android phone

Open GlowDeckTV in Android Studio > Build APK(s).
Android phone/tablet: install app/build/outputs/apk/debug/app-debug.apk
(transfer APK and tap to install, or adb install -r path-to-app-debug.apk).
Windows USB helper: BUILD_AND_INSTALL_ANDROID.bat
Fire TV helper: BUILD_AND_INSTALL.bat
Same LAN as WLED devices. Fireplace default = 192.168.1.71.
